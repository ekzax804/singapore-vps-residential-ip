很多人搞不清"住宅IP"到底有什么用。简单说，数据中心IP来自IDC机房，IP段集中、容易被识别，很多平台（TikTok、亚马逊、流媒体）会限制或封禁这类IP；住宅IP来自真实的ISP宽带网络，看起来像普通家庭用户，平台风控宽松得多。

换句话说，拿到IP后最好先用ipinfo.io、IPQualityScore这类工具查一下类型，再到目标平台（比如TikTok）实际跑一遍，确认没问题再正式使用。别光看商家描述就直接上业务。
